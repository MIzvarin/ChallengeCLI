# Storage

- Исходный файл: `storage.py`
- Версия документа: 0.1.1
- Дата изменения: 2026-11-09

## Назначение
Локальное хранилище SQLite для одного пользователя.

## Основные обязанности
- Хранит снимки профиля, историю целей, сообщения, изменения по дням и сводки.
- Сохраняет структурированные события без текстов переписки и ключей.
- Каждая операция использует собственное соединение, совместимое с рабочими потоками.
- Соединение всегда закрывается; ошибки откатывают транзакцию.
- Профиль и новая цель записываются одной транзакцией; последняя запись актуальна.

## Особенности
База не зашифрована. Каталог создаётся с правами 700, файл с правами 600.
История не удаляется при суммаризации. Отложенный опрос не меняет дату измерений.
