# Storage

- Исходный файл: `storage.py`
- Версия документа: 0.1.5
- Дата изменения: 2026-11-11

## Назначение
Локальное хранилище SQLite для одного пользователя.

## Основные обязанности
- Хранит снимки профиля, историю целей, сообщения, изменения по дням и сводки.
- Сохраняет структурированные события без текстов переписки и ключей.
- Каждая операция использует собственное соединение, совместимое с рабочими потоками.
- Соединение всегда закрывается; ошибки откатывают транзакцию.
- Профиль и новая цель записываются одной транзакцией; последняя запись актуальна.
- clear очищает все семь таблиц и создаёт новый ID сессии в одной транзакции.
- chat_messages возвращает всю переписку по порядку записи, включая статусы запросов.
- history отдельно отбирает завершённые записи с заданной даты для контекста LLM.
- token_usage агрегирует api_request/api_usage всей переписки, без лимита 200 событий.
- При include_history=True возвращает также накопленную известную сумму для каждого обращения.
- Отчёт и точки графика вычисляются за один проход по одной выборке аудита, без миграции БД.
- Счётчики восстанавливаются из существующего аудита после перезапуска и сбрасываются /clear.
- Пропущенная статистика не заменяется нулём; кеш не прибавляется повторно ко входу.

## Особенности
База не зашифрована. Каталог создаётся с правами 700, файл с правами 600.
История не удаляется при суммаризации. Отложенный опрос не меняет дату измерений.
Очистка логическая: не является гарантией физического стирания с диска или из резервных копий.
Файлы вне SQLite, в том числе .env, не затрагиваются.
