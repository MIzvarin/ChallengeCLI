# FitAgentApp

- Исходный файл: `ui.py`
- Версия документа: 0.1.30
- Дата изменения: 2026-11-28

## Назначение
Главный минималистичный Textual-интерфейс FitAgent.

## Основные обязанности
- При открытии чата с заполненным профилем и после завершения опроса запускает MCP плана дня,
  если в SQLite ещё нет актуального сегодняшнего плана. Генерация выполняется в фоне.
- Показывает сохранённый план дня в общей ленте с предупреждениями безопасности.
  План подхватывается из SQLite, в том числе если его подготовило другое окно.
- Если соседнее окно освободило резерв без сохранения плана, повторяет попытку.
  Сообщения об ошибках попадают в основной чат, даже если открыт график токенов.
- Команда /wake сохраняет привычное время подъёма для следующих планов.
- Подхватывает новые сохранённые корзины из SQLite в открытом окне. Команда /plan последняя корзина показывает последнюю покупку без нового подбора.
- Показывает выпадающий список «Мужской» и «Женский» на шаге выбора пола.
- В еженедельном напоминании предлагает сообщать об изменениях режима и цели.
- Команда /plan вызывает локальный MCP в рабочей задаче TUI.
- Передаёт `/training` и фразу подтверждения в чат. После согласования или приостановки программы
  запускает обновление плана дня в фоне.
- Отображает текущий профиль, цель, чат и сообщения об ошибках.
- Показывает этап конвейера рядом с целью; справка объясняет принятие плана и корректировки.
- При открытии сервис добавляет вопрос о прогрессе, если цель на выполнении; API не вызывается.
- Обрабатывает /profile, /progress, /logs, /tokens, /clear, /help, /exit и клавиатурные команды.
- /memory показывает факты с номерами, источниками, сроками и необходимостью перепроверки.
- /memory edit НОМЕР текст исправляет факт, /memory delete НОМЕР удаляет его версии.
- Команды памяти не обращаются к API, не выполняются во время ответа; ошибки на русском.
- После явной команды памяти прокручивает чат к её результату, даже если до этого пользователь
  читал старые сообщения. Журнал показывает обычный текст «Было / Стало», без JSON.
- `/help` сообщает об использовании DeepSeek Flash для памяти и проверок безопасности
  и указывает на условия обработки данных Go.
- Справка объясняет приоритет последнего сообщения, немедленное применение новой редакции,
  подтверждение критичных замен и безопасные события изменения фактов в /logs.
- Справка объясняет постоянный номер факта и просмотр его журнала через /memory history.
- Изменение значения показывает как «Факт №НОМЕР обновлён», повтор того же значения —
  «Актуальность факта подтверждена». Новые обновления не показывают переходы номеров.
- Темы переключаются автоматически, без /topics, /resume и ручных команд переключения.
- Показывает отметки новой темы, возврата, отступления и смешанного вопроса в общей ленте.
- При запуске восстанавливает отметки переходов; сбой косметической отметки не скрывает ответ.
- /tokens открывает TokensScreen с накопленным расходом и тем же блоком счётчиков, что в /logs.
- /exit закрывает приложение из поля чата, не удаляя данные и не обращаясь к API.
- Подсказка команд и /help содержат /exit; Ctrl+Q остаётся доступен во время опроса.
- /clear без подтверждения очищает данные и чат, начинает первичный пошаговый чат-опрос.
- Не выполняет очистку во время ответа или из другого модального окна.
- При запуске продолжает незавершённый опрос; отдельных окон профиля и риска нет.
- /profile и Ctrl+P показывают данные только для чтения, не открывая форму.
- Изменения и подтверждение риска выполняются через чат, /confirm и /cancel.
- Раз в неделю напоминает сообщить изменения; полный опрос повторно не проводится.
- Приоритетный Ctrl+Q работает в модальных окнах; палитра Textual отключена для Ctrl+P.
- Выполняет API-сценарии в рабочем потоке; блокирует параллельную отправку вопросов.
- Показывает ResponseLoader во время ожидания; скрывает его и при успехе, и при ошибке.
- При запуске восстанавливает все сообщения из SQLite, без недельного фильтра и лимита строк.
- Сохраняет Markdown ответов; помечает неудачные и незавершённые вопросы без повтора API.
- При ошибке чтения истории показывает понятное сообщение без технических подробностей.
- /logs и Ctrl+L переключают нижнюю LogsPanel, не открывая модальное окно.
- Справка описывает активность, предупреждения/блокировки и ошибки проверок в /logs.
- Успешные проверки скрыты; лента не содержит текстов диалога и личных данных.
- Панель оставляет чат и ввод доступными; доступна также во время ожидания ответа.
- Обновляет видимую панель сразу после ответа, ошибки и /clear.
- Оформляет вопросы и ответы отдельными монохромными блоками с рамкой и отступами.
- Единое оформление новых и восстановленных сообщений вынесено в chat.write_message.
- Подпись автора закреплена в рамке; сообщения пользователя не интерпретируются как Markdown.
- Markdown ответов сохраняется; статус неудачного/незавершённого вопроса находится в его блоке.

## Особенности
Тёмный монохром: отдельные рамки сообщений, тихие подсказки, простая строка ввода и заголовок.
Журнал и предупреждения используют нейтральные оттенки серого.
Сброс рамки применяется только к чату, не скрывая разделитель ленты LogsPanel.
Вся переписка доступна прокруткой; LLM получает активную тему/checkpoint и применимые факты.
Отображение всей истории требует памяти, пропорциональной её объёму.
Напоминания работают только при запущенном приложении.
