# SafetyGuard

- Исходный файл: `safety.py`
- Версия документа: 0.1.3
- Дата изменения: 2026-11-17

## Назначение
Отдельная проверка безопасности через Luna до генерации и до показа ответа.

## Основные обязанности
- Передаёт ограничения, лекарства, добавки и профиль независимому валидатору.
- При подтверждении исправления передаёт также прежние правила, не теряя покрытие проверки.
- Новые запреты учитываются вместе со старыми ещё до подтверждения изменения записи.
- Передаёт программу и режим как дополнительные данные, чтобы учитывать риски вне категорий.
- Получает актуальную/предлагаемую цель и контекст диалога для разрешения коротких ссылок.
- Проверяет все обязательные rule_id без искусственного лимита 64; лимит вывода API сохраняется.
- Проверяет закрытую схему, покрытие правил и согласованность итогового статуса.
- Строгость назначает Luna по данным; неизвестные подробности дают предупреждение.
- Возвращает основной модели только статус и краткое описание, без массива checks.
- Блокирует конкретный запрос при block, сбое API или некорректном протоколе.
- При отказе объясняет, что нельзя выполнить на данном этапе, и приводит краткую причину Luna.
- Предлагает безопасный вариант/другой вопрос; ошибочные ограничения исправляются с подтверждением.
- Сообщение о сбое проверки отличается от отказа из-за риска и не объявляет вопрос опасным.
- Для сбоя пишет этап, фазу получения/валидации, тип ошибки и фиксированный код причины.
- Ошибки протокола уточняют путь поля схемы, счётчики покрытия/длины и допустимые статусы.
- Не пишет содержимое ответа, описания рисков, номера правил или персональные данные.

## Особенности
Модель не гарантирует смысловую точность; строгий протокол не является медицинской гарантией.
