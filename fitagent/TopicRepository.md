# TopicRepository

- Исходный файл: `topic_storage.py`
- Версия документа: 0.1.0
- Дата изменения: 2026-11-14

## Назначение
Хранение автоматических веток, привязок сообщений, переходов и checkpoint-сводок.

## Основные обязанности
- Добавляет таблицы без удаления или семантического разбора старой переписки.
- Читает каталог тем, активную тему, её сообщения и последний checkpoint.
- Записывает переход, checkpoint и привязки обеих реплик в транзакции ответа и фактов.
- Проверяет исходное состояние перед записью, не оживляет данные после /clear.
- Возвращает отметки переходов для восстановления общей хронологической ленты.

## Особенности
Ранее неразмеченные сообщения первого обсуждения остаются одной общей веткой.
Их группировка локальна, не вызывает API и не выдаётся за распознанные старые темы.
Названия, тексты и сводки не пишутся в технический аудит.
