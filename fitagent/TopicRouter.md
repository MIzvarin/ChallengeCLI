# TopicRouter

- Исходный файл: `topics.py`
- Версия документа: 0.1.2
- Дата изменения: 2026-11-16

## Назначение
Проверка автоматической маршрутизации диалога и подготовка checkpoint-контекста.

## Основные обязанности
- Передаёт каталог и состояние активной темы в общий запрос Luna с извлечением фактов.
- Проверяет continue/switch/resume/detour/mixed и существование всех ссылок на темы.
- Создаёт отдельную ветку отступления и сохраняет родительскую тему.
- Назначает тему-источник фактов отдельно от global/topic области их применения.
- Перед сменой темы создаёт Flash-сводку исходной ветки с датами и границами сообщений.
- При возврате использует checkpoint и недавние непокрытые сообщения только выбранной темы.
- Для смешанного вопроса подключает сводки явно связанных тем, не объединяя их истории.
- Возвращает только числовые границы реально включённых в контекст checkpoint для журнала.
- После завершения задачи не принимает закрытую ветку за неразмеченную старую историю.

## Особенности
Старый checkpoint — состояние обсуждения, не актуальный профиль и не источник новых фактов.
Решения пользователя и рекомендации ассистента разделяются инструкцией модели.
Смысловая корректность маршрута и сводки зависит от модели, не гарантируется JSON Schema.
Ручных команд переключения нет. Ошибки не фиксируют ни ветку, ни факты, ни checkpoint.
