# ModelClient

- Исходный файл: `provider.py`
- Версия документа: 0.1.3
- Дата изменения: 2026-11-11

## Назначение
Прямой HTTPS-клиент OpenAI-совместимого API OpenCode Go.

## Основные обязанности
- Отправляет ключ, честный User-Agent и стабильный идентификатор разговора.
- Возвращает текст, сообщает об ошибках и отсечённых ответах.
- Некорректный JSON преобразуется в безопасное сообщение без тела ответа.
- Передаёт в аудит только назначение запроса, статус и числовую статистику.
- Сохраняет usage до проверки текста, включая обрезанные, пустые и неверные ответы.
- Принимает только неотрицательные целые счётчики; неверные и отсутствующие — null.

## Особенности
При max_tokens=None не передаёт ограничение генерации в API, даже в виде null.
Числовой лимит отправляет только при явно указанном бюджете (для сводок).
Нет автоматических повторов, чтобы не дублировать расходы.
Отсутствие статистики кеша обозначается null, а не ложным попаданием в кеш.
Применимость Go к фитнес-чату не гарантируется провайдером.
