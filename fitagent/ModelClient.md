# ModelClient

- Исходный файл: `provider.py`
- Версия документа: 0.1.7
- Дата изменения: 2026-11-17

## Назначение
Прямой HTTPS-клиент OpenAI-совместимого API OpenCode Go.

## Основные обязанности
- Отправляет ключ, честный User-Agent и стабильный идентификатор разговора.
- Возвращает текст, сообщает об ошибках и отсечённых ответах.
- Подсказки связи не обещают технические детали в упрощённом /logs.
- Некорректный JSON преобразуется в безопасное сообщение без тела ответа.
- Передаёт в аудит только назначение запроса, статус и числовую статистику.
- Сохраняет usage до проверки текста, включая обрезанные, пустые и неверные ответы.
- Принимает только неотрицательные целые счётчики; неверные и отсутствующие — null.
- generate_structured использует gpt-6-luna через нативный Responses API Go с тем же ключом.
- Передаёт text.format=json_schema, strict=true, store=false и reasoning.effort=none.
- Не принимает отказы, незавершённый ответ, инструменты или пустой результат как факты.
- Usage Responses сохраняется до проверки результата; нет перехода на обычный JSON/текст.
- Отдельные safety_* вызовы Luna используют свою строгую схему и отдельный учёт расхода.
- Для safety_* различает отсутствие ключа, HTTP/сетевой сбой, тайм-аут, незавершённый,
  обрезанный, пустой ответ, отказ модели и неверный протокол через SafetyValidationError.
- Передаёт только фиксированный код причины и HTTP-статус, без тела ответа и ключа.

## Особенности
При max_tokens=None не передаёт ограничение генерации в API, даже в виде null.
Числовой лимит отправляет для сводок; для памяти max_output_tokens=8192.
Память всегда направляется на https://opencode.ai/inference/go/openai/v1/responses;
FITAGENT_API_URL и FITAGENT_MODEL меняют только чат/оценку цели/суммаризацию.
store=false не отменяет журналирование безопасности OpenAI (до 30 дней по условиям Go).
Нет автоматических повторов, чтобы не дублировать расходы.
Отсутствие статистики кеша обозначается null, а не ложным попаданием в кеш.
Применимость Go к фитнес-чату не гарантируется провайдером.
