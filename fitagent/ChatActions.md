# ChatActions

- Исходный файл: `chat_actions.py`
- Версия документа: 0.1.4
- Дата изменения: 2026-11-18

## Назначение
Подтверждение изменений профиля, ограничений и завершения задач/целей через чат.

## Основные обязанности
- Проверяет цитату изменения, параметры, безопасность и предупреждения цели.
- Хранит предложения с номером, ревизией памяти и сессией; не принимает устаревшее согласие.
- /confirm НОМЕР применяет предложение, /cancel НОМЕР отменяет без изменения фактов.
- Повторно проверяет безопасность подтверждаемых профиля и ограничений отдельным вызовом Luna.
- Проверяет бюджет кандидата до подтверждённого сохранения; при отказе предложение не расходуется.
- Сохраняет контекст предложения для проверки при подтверждении; оценка цели проверяется до показа.
- При подтверждении block отклоняет изменение; advisory-предупреждение показывается без цикла согласий.
- Завершает задачу только после подтверждения; удаляет checkpoint и исключает её из контекста.
- Архивирует среднесрочную память при достижении цели, сохраняя измерения и текущие режимы.
- Сохраняет ограничения, предпочтения и историю; не подменяет архив физическим удалением.
- В конвейере изменение желаемой цели не разрешает выполнение: после подтверждения нужна валидация.
- Не предлагает завершение цели на планировании/валидации; подтверждение сверяет с целью,
  принятым планом и отпечатком данных именно предложения о достижении, включая новый вес.
- Независимые задачи/темы закрываются без активной цели и независимо от её этапа.
- Отмена достижения, изменившего данные, возвращает цель на валидацию, не разрешая старый план.
- Старые предложения завершения без привязки отклоняет с просьбой заново сообщить о достижении.
- Архивирование и переход выполнение → готово происходят одной транзакцией.
- Для предложения завершения использует подготовленный этап из кандидата ответа;
  читает состояние из БД только при отсутствии кандидата.
- prepare не принимает неиспользуемый результат безопасности; необходимые проверки выполняет сам.

## Особенности
Оригинальная переписка остаётся доступной в ленте, но закрытые обсуждения не восстанавливаются в LLM.
