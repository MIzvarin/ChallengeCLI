# TokensScreen

- Исходный файл: `token_chart.py`
- Версия документа: 0.1.0
- Дата изменения: 2026-11-11

## Назначение
Отдельное окно /tokens для анализа расхода в длинной переписке.

## Основные обязанности
- Дублирует верхний блок /logs через общий TokenSummary с теми же стилями и данными.
- Показывает накопленный расход всех обращений к API через TokenChart.
- Загружает отчёт и историю одной операцией; обновляет их каждые две секунды.
- Закрывается по Escape или кнопке, не меняя чат и данные пользователя.
- Преобразует ошибки чтения в безопасные русские подсказки.

## Особенности
Читает только локальный аудит без лимита 200 событий. Не вызывает API и не тратит токены.
Показывает известную сумму, не подменяя отсутствие статистики нулём.
Счётчики и номера обращений сохраняются после перезапуска и сбрасываются через /clear.
