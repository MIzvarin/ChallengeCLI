# LogsPanel

- Исходный файл: `logs.py`
- Версия документа: 0.1.3
- Дата изменения: 2026-11-12

## Назначение
Нижняя панель технического аудита и расхода токенов, не перекрывающая чат.

## Основные обязанности
- Показывает последние 200 событий без содержимого переписки.
- Показывает вход всего контекста и выход текущего/последнего запроса чата.
- Показывает накопленный расход всех обращений к API и неполноту статистики.
- Обновляется каждые две секунды, только когда видима; не перезаписывает неизменный журнал.
- При ошибках чтения показывает понятную русскую подсказку без исключений.
- Закрепляет счётчики над независимо прокручиваемой лентой событий.
- Отделяет счётчики рамкой и контрастным фоном; выделяет числа, итог и заголовки жирным.
- Подписывает разделитель ленты «Лента событий»; верхняя подсказка находится в рамке панели.
- Использует общий TokenSummary, идентичный верхнему блоку окна /tokens.
- Выделяет синим только названия summary_started, summary_finished и summary_cache_hit.

## Особенности
FitAgentApp переключает видимость по /logs и Ctrl+L, обновляет после ответа и очистки.
Подсчёт выполняется отдельно, по сохранённой статистике API, без токенизатора.
Оформление монохромное, кроме названий событий компакта; даты и параметры не окрашиваются.
На узком экране длинная статистика прокручивается отдельно от ленты.
