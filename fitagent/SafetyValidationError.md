# SafetyValidationError

- Исходный файл: `safety_schema.py`
- Версия документа: 0.1.0
- Дата изменения: 2026-11-17

## Назначение
Ошибка результата проверки безопасности с безопасной диагностикой для журнала.

## Основные обязанности
- Сохраняет совместимость с ValueError и понятное пользователю сообщение SAFETY_ERROR.
- Передаёт фиксированный код причины, путь поля схемы, счётчики и допустимые статусы.
- Для транспортных/серверных сбоев передаёт безопасный код причины и HTTP-статус.
- Отбрасывает неизвестные поля, произвольные строки и значения вне допустимых границ.

## Особенности
Не содержит текстов ответов, описаний рисков, ключей, значений профиля или номеров правил.
Диагностика не меняет решение проверки и не разрешает некорректный результат.
