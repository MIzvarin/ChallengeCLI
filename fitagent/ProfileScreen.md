# ProfileScreen

- Исходный файл: `ui.py`
- Версия документа: 0.1.2
- Дата изменения: 2026-11-09

## Назначение
Форма первоначального заполнения и подтверждения актуальности профиля.

## Основные обязанности
- Собирает обязательные параметры и цель, необязательный целевой вес.
- Запускает валидацию и оценку цели без блокировки интерфейса.
- Требует подтверждение предупреждений, позволяет отложить повторный опрос на сутки.
- Показывает русские подсказки валидации; скрывает тексты неожиданных технических ошибок.
- В аудит ошибок сохранения передаёт только тип исключения, без его содержимого.

## Особенности
Поля прокручиваются отдельно; заголовок, сообщения и кнопки остаются видимыми.
Для оценки цели нужен рабочий API-ключ. При ошибке значения формы сохраняются.
Первичное заполнение нельзя отложить; выйти из приложения можно Ctrl+Q.
