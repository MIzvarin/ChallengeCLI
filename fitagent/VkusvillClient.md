# VkusvillClient

- Исходный файл: `vkusvill.py`
- Версия документа: 0.1.1
- Дата изменения: 2026-11-24

## Назначение
Анонимное подключение к официальному MCP ВкусВилла без доступа к аккаунту.

## Основные обязанности
- Выполняет initialize, уведомление initialized и разрешённые tools/call.
- Поддерживает JSON и SSE, проверяет номера ответов и ограничивает размер ответа.
- Ищет товары с полными свойствами и создаёт ссылку из ID и количеств.
- Не передаёт ключ модели, историю, профиль или авторизацию ВкусВилла.
- Не следует перенаправлениям и не использует учётные данные из окружения.
- Проверяет точный набор полей вызова; произвольные дополнительные данные не отправляет.
- Заменяет технические ошибки понятным русским сообщением.

## Особенности
Фиксированный HTTPS endpoint; разрешены поиск, карточка и ссылка на корзину.
Никаких заказов, оплаты, персональных скидок и истории покупок.
При тайм-ауте, временном сетевом сбое или HTTP 408/429/500/502/503/504 поиск
повторяется до двух раз, каждый раз с новой MCP-сессией. Паузы — 0,5 и 1 секунда;
если сервер просит ждать дольше 5 секунд, автоматического повтора нет.
Поисковая строка и текст ошибки в журнал повторов не попадают.
Ошибки формата ответа и вызовы для создания ссылки не повторяются.
Ссылки принимаются только с HTTPS-домена vkusvill.ru.
Для тестов поддерживается подмена транспорта HTTPX.
