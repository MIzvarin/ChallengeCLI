# SafetyArgumentParser

- Исходный файл: `check_safety.py`
- Версия документа: 0.1.0
- Дата изменения: 2026-11-16

## Назначение
Понятные русские ошибки параметров локального скрипта проверки безопасности.

## Основные обязанности
- Заменяет техническую ошибку argparse русской подсказкой о формате команды.
- Не выводит необработанные аргументы, которые могут содержать чувствительные сведения.
